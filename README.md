# graded-geo — Claude Code plugin (marketplace)

Commodity GEO fixes for a website repository: read what AI can fetch, diagnose on a four-answer
card, fix as pull requests, advertise the fact file where models read, recheck with the same free
tools. A human merges. By [Graded](https://usegraded.com).

## Install

```bash
claude plugin marketplace add GradedLabs/graded-geo-plugin
claude plugin install graded-geo@graded-geo-plugin
```
