# .graded/runs/<YYYY-MM-DD>/ — one Graded GEO walk

Copied from the plugin's `_templates/run/` by stage 01. One file per stage. The highest-numbered
file present is where the run stands; a file whose last line is `Done: no` is in progress.

A person may edit any file between stages; the next stage reads what is here, not what the agent
remembers. Commit this folder on the fix branches so every pull request carries its receipt.

Nothing in these files is a score. "not measured here" is a blank, never a zero.
